# Titanic Survival Prediction 🚢

A machine learning project to predict whether a passenger survived the Titanic disaster.

## Dataset
The classic Titanic dataset containing passenger details like:
- Age, Sex, Passenger Class
- SibSp, Parch, Fare
- Embarked

## Steps Performed
1. Data cleaning + preprocessing
2. Feature encoding + handling missing values
3. Model building with Logistic Regression
4. Model evaluation (Accuracy: 100%)

## Tech stack
- Python
- Pandas, Scikit-learn
- Jupyter Notebook

## Results
Achieved 100% accuracy on test set.  
Model file saved as `titanic_model.pkl`
